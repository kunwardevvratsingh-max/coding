# AlgoAscent: Competitive Programming

A comprehensive repository dedicated to advanced data structures, algorithms, and competitive programming, developed during the **AlgoAscent** program under the **Materials Society, IIT Kanpur** (Dec'25 - Jan'26).

This repository contains robust C++ implementations designed to optimize problem-solving efficiency, focusing on minimizing runtime and mastering core algorithmic patterns.

## 🚀 Objective
The primary goal of this initiative was to master advanced data structures and competitive programming techniques, strengthening core DSA foundations for technical interviews and complex algorithmic troubleshooting workflows.

## 🛠️ Core Methodologies & Approach
Throughout the program, problem-solving techniques were categorized into systematic optimization workflows:
* **Window & Pointer Optimizations:** Implemented *Sliding Window*, *Two-Pointer*, and *Prefix Sum* techniques to reduce naive time complexities from $O(N^2)$ to $O(N)$.
* **Algorithmic Paradigms:** Deep-dived into *Dynamic Programming (DP)* for overlapping subproblems and optimal substructures, alongside *Greedy Algorithms* for locally optimal choices.
* **Contest Simulations:** Participated regularly in rigorous biweekly platform contests and live, competitive **Codeforces** simulations to build speed and accuracy under pressure.
